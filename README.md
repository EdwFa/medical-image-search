# 🔍 Реверсивный поиск медицинских изображений (MVP)

Данный проект представляет собой веб-приложение (MVP), разработанное для исследователей, научных редакторов и рецензентов. Его главная цель — быстрый поиск плагиата, дубликатов и первоисточников медицинских и биомедицинских изображений (рентгеновских снимков, графиков, гистологии и др.) в глобальной сети Интернет.

## 🚀 Что сделано на данный момент

Приложение успешно реализует полный цикл реверсивного поиска:

1. **Графический интерфейс (Streamlit)**
   - Простой и интуитивно понятный UI для загрузки изображений в форматах `.jpg`, `.jpeg`, `.png`, `.webp`.
   - Мгновенное превью загруженного изображения.

2. **Интеграция с глобальным CDN (ImgBB)**
   - Чтобы обойти региональные блокировки (в том числе "Великий китайский файрвол") и позволить любым поисковикам прочитать изображение, реализована автоматическая загрузка картинки на хостинг ImgBB через API.
   - Изображение становится временно доступным по прямой глобальной ссылке для поисковых ботов.

3. **Генератор запросов к глобальным поисковикам**
   В один клик приложение генерирует прямые ссылки для поиска картинки в крупнейших поисковых системах:
   - 🔍 **Google Lens** (мировой стандарт)
   - 🔍 **Yandex Images** (отлично ищет по рунету)
   - 🔍 **Bing Visual Search**
   - 🔍 **TinEye** (специализируется на строгих совпадениях и плагиате)

4. **Поддержка азиатского сегмента (Китайские поисковики)**
   - 🇨🇳 **Baidu (百度)**
   - 🇨🇳 **Sogou (搜狗)**
   Интеграция китайских систем позволяет находить плагиат в статьях и ресурсах, которые часто игнорируются западными поисковиками.

5. **Специализированный "Научный поиск"**
   Реализован отдельный блок для фильтрации "мусорных" результатов:
   - 📚 **Yandex (только PubMed):** Автоматически добавляет текстовый фильтр `site:ncbi.nlm.nih.gov` к визуальному поиску, оставляя только совпадения в опубликованных статьях.
   - 🧬 **Open-i (NIH):** Интеграция с открытой базой Национального института здравоохранения США для ручной проверки по биомедицинским открытым данным.

## 🛠 Технологический стек

- **Python 3.x**
- **Streamlit** (Фреймворк для веб-интерфейса)
- **Requests** (Взаимодействие с API)
- **Pillow / PIL** (Обработка изображений)

## ⚙️ Установка и запуск

1. Убедитесь, что у вас установлен Python.
2. Склонируйте или скачайте проект, затем перейдите в папку `image_search`.
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   streamlit run app.py
   ```
5. Приложение автоматически откроется в вашем браузере по адресу `http://localhost:8501`.

## 📝 Настройка (API Ключи)
Для корректной работы приложения в файле `search_engine.py` используется API ключ сервиса **ImgBB**. Если лимит запросов ключа будет исчерпан, вам потребуется зарегистрироваться на [api.imgbb.com](https://api.imgbb.com/) и заменить переменную `api_key` на свой токен.
